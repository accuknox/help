# Cached accuknox.com URL inventory

Generated by `../scripts/refresh_sources.py` from
`https://accuknox.com/sitemap.xml`. Do not hand-edit any file here. An edit is
overwritten on the next rebuild.

Ten buckets, one markdown table each, newest first. Every row carries the last
modified date, the slug and the live URL. Append `.md` to any URL to read the
page as agent-friendly markdown.

```bash
python ../scripts/refresh_sources.py --check   # exits 1 when a bucket is 30 days old
python ../scripts/refresh_sources.py           # rebuild
```

**This index is not proof.** The sitemap omits live pages and keeps dead ones.
`platform/aispm` returns 200 and is absent here. `platform/prompt-firewall` is
linked from a published post and returns 404. Run
`../scripts/verify_links.py <draft.md>` before shipping anything.
