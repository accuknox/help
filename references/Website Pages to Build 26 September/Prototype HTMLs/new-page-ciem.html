01

Every Identity Sits in One List

Open Identities > CIEM to see the users, groups and roles from every onboarded cloud account.

CIEM marks each identity as human or machine. A CI/CD pipeline account counts as a machine identity.

  • Filter by cloud, identity type, name and date range.
  • Read the cloud ID in one column: an ARN on AWS, a service account ID on GCP, an OCID on OCI.
02

Stale Access Shows Up in the Lifecycle Columns

Scroll the list right. Each identity shows its age, who created it and when it last acted.

  • Age In Days
  • Created By
  • Last Used
  • Days Since Last Used

A high Days Since Last Used value marks a role nobody touched in months.

03

The Access Graph Shows How an Identity Got Its Access

Select an identity. The graph reads top to bottom: the identity, its groups, then the policies each group grants.

The Overview tab lists every attached policy and opens the policy document as JSON. CIEM tags each identity with the risk classes its policies carry.

  • Privilege Escalation
  • Data Exfiltration
  • Credentials Exposure
  • Infrastructure Modification
04

One Graph Counts Every Identity in an Account

Switch to the graph view. Each node shows a count, so you see the size of an account's identity footprint at a glance.

In the sample AWS account, the badges read 77 users, 22 groups, 637 roles and 504 policies.

05

Turn On CIEM While You Onboard a Cloud Account

CIEM is part of the normal cloud account onboarding. The CIEM toggle is on by default.

  1. Pick the cloud

    Go to Settings > Cloud Accounts > Onboard Account. Choose the provider and Standalone Account.

  2. Keep CIEM on

    In Configure Scanning, leave the CIEM toggle on and select Next.

  3. Connect the account

    On AWS, run the Terraform script, then paste the keys it creates.

Two Limits Apply at Launch

  • CIEM supports standalone cloud accounts. Organization accounts are not supported yet.
  • CIEM covers cloud identities. For Kubernetes service accounts and roles, use KIEM.

CIEM Questions

Which clouds does AccuKnox CIEM cover?

AWS, GCP, Azure and Oracle Cloud Infrastructure.

What counts as a machine identity?

An identity that software uses, such as a CI/CD pipeline account. CIEM marks every identity as human or machine.

Where does the risk class come from?

CIEM calculates it from the policies attached to the identity. Examples are Privilege Escalation and Data Exfiltration.

Does CIEM support AWS Organizations?

Not yet. CIEM supports standalone cloud accounts today.

How do I turn it on?

Leave the CIEM toggle on when you onboard a cloud account. The onboarding guide has the steps.
