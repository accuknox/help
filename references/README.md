# references

Support assets for agentic tasks and content generation. Not published as documentation.

## Folders

### `3x Blog Series - Emerging Threats from AI-Driven Attacks/`
Source material and drafts for the 3-part prompt-guardrails blog series (voice agents, multi-turn jailbreaks, indirect prompt injection). Holds the `.docx` brief, the three blog markdown files, chart images, and the raw research PDFs/docs in `reference-files/`.

### `prd-ai-soc/`
AI SOC go-to-market package: the Excel data package, pitch deck, and wireframes, plus `competitor-screens/` (13 competitor UI captures) and `raw-research/` (market and vendor teardown notes).

### `prd-dspm/`
DSPM competitive analysis site: a 10-page HTML report (`dspm-analysis/`) covering the executive summary, competitor cards, feature matrix, and next steps, plus a standalone `dspm-competitive-analysis.html`.

### `brian-demo-screenshots/`
22 curated, captioned product screenshots for AI-security assets (dashboard, findings, AI red teaming, prompt firewall, runtime protection, zero-trust discovery). Caption index in `DEMO-SUMMARY.md`. Use these first for polished blog and deck imagery.

### `comparisons-builder/`
Competitive comparison spreadsheets (AccuKnox vs Checkpoint, Promptfoo, RHACS/NeuVector, Straiker, Invicti) plus the battlecard build script. Used for battlecards and sales collateral.

### `content-planning/`
Platform pages content plan and prompt files for content generation runs. Flagged outdated by `seo/README.md` — don't treat as the SEO source of truth.

### `private-cloud-onboarding-openshift/`
OpenShift private-cloud onboarding walkthrough: step docs, an English walkthrough, two screen-recording MP4s with an SRT transcript, and open questions for Murtaza.

### `reports/`
Generated reports and design documents: the CWPP report PDF and build script, the Security Graph UI design brief and competitive analysis doc, and the supporting competitive-analysis images.

### `rfp-generation/`
RFP response generation scripts (`scripts/`) and output files (`responses/`, including `client-rfps/` for inbound client RFPs). Covers both standard RFP responses and SLA documents.

### `technical-reference/`
Internal reference PDFs: playbooks (CWPP, ASPM, VM security), architecture docs, POC prerequisites, Kubernetes hardening guidance, audit/compliance reports (SOC2, ISO 27001), and the SLA escalation matrix. Read-only, do not edit.
