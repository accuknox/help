Prisma Cloud integrates with IBM Cloud Security Advisor. To enable the integration, you must provide credentials, which consist of an [Account GUID](https://cloud.ibm.com/docs/account?topic=account-userapikey&interface=ui) and [API Key](https://cloud.ibm.com/docs/account?topic=account-manapikey).
