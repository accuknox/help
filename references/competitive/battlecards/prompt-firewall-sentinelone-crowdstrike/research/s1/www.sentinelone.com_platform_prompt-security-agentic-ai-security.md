## Frequently Asked Questions

### What is Agentic AI Security?

Agentic AI Security discovers every AI agent and MCP server in your environment, enforces risk-based policy on what they can access and do, and produces a searchable audit log of every action.

### What is an MCP server, and why does it matter?

An MCP server lets AI agents connect to and act on external systems. Unsanctioned or unmonitored MCP servers give agents unmanaged access to sensitive systems, often invisible to existing security tools.

### How does SentinelOne handle shadow MCP servers?

SentinelOne automatically discovers MCP servers running in your environment, sanctioned or not, and risk-scores each one so unauthorized deployments surface before they're exploited.

### Can SentinelOne stop an agent in real time?

Yes. Policy is enforced at the same speed agents act, blocking violations before they propagate across connected systems.

### How quickly can Prompt Security be deployed?

Prompt Security deploys in minutes. No complex integrations or infrastructure changes are required. Organizations see immediate protection and visibility upon deployment.

### How does Agentic AI Security fit into the Singularity Platform?

Agentic AI Security runs in the same console that protects your endpoints, identities, and cloud. Agent risk signals sit alongside the rest of your security telemetry.
