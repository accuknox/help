Need Answers?

## Frequently Asked Questions

### What is AI Usage Control?

AI Usage Control is SentinelOne's platform for governing how employees and developers use AI. It gives you real-time visibility into every AI tool in use, enforces policy automatically, and redacts sensitive data before it reaches a public model.

### How does AI Usage Control find shadow AI?

It detects usage across 15,000+ AI websites and services, the largest AI tool library in the category, so unsanctioned tools surface before they become a data incident.

### Does it work with AI code assistants?

Yes. AI Usage Control covers every AI code assistant in your environment, including GitHub Copilot, Cursor, and Claude Code. Security teams decide which tools are sanctioned and block the rest.

### How does redaction work?

Sensitive data is redacted at the edge, in line, before a prompt leaves the device. Employees get coached in the moment instead of having their work blocked outright.

### How fast can we deploy?

AI Usage Control deploys in minutes. There are no complex integrations or infrastructure changes, and protection starts immediately.

### How does it fit into the Singularity Platform?

AI Usage Control runs in the same console that protects your endpoints, identities, and cloud. Governance policies and AI risk visibility live alongside the rest of your security telemetry.
