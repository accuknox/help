## Firefox Collector [​](https://aidr-docs.crowdstrike.com/docs/aidr/collectors/browser/firefox\#firefox-collector "Direct link to Firefox Collector")

The AIDR Firefox collector monitors and controls AI usage in managed Firefox browsers.
The Firefox add-on is available from the collector **Install** page in the AIDR console.

### Requirements [​](https://aidr-docs.crowdstrike.com/docs/aidr/collectors/browser/firefox\#requirements "Direct link to Requirements")

- **Subscription:** AIDR for Workforce

- **Default roles:** AIDR Admin role explicitly assigned to your Falcon user for the current customer account

- **Permissions required for custom roles:**
  - Manage AIDR findings and workforce collectors
  - Read AIDR data from LogScale
  - Read AIDR findings and workforce collectors
- **CrowdStrike clouds:** Available in US-1, US-2, and EU-1

- **Network:** HTTP access to
[AIDR origins](https://aidr-docs.crowdstrike.com/docs/aidr#cloud-origins)


- **Supported operating system:**
  - Windows
  - macOS
- **System access:** Admin privileges on user machines to update system-level configuration:
  - Registry on Windows
  - Configuration profile on macOS

### Get started [​](https://aidr-docs.crowdstrike.com/docs/aidr/collectors/browser/firefox\#get-started "Direct link to Get started")

1. [Register](https://aidr-docs.crowdstrike.com/docs/aidr/collectors/browser/firefox/register) \- Register a Firefox browser collector in the AIDR console and configure policy rules.
2. [Deploy](https://aidr-docs.crowdstrike.com/docs/aidr/collectors/browser/firefox/deploy) \- Deploy the extension using Group Policy or self-service installation.
3. [Verify deployment](https://aidr-docs.crowdstrike.com/docs/aidr/collectors/browser/firefox/verify) \- Confirm the extension status and data flow to the AIDR console.
