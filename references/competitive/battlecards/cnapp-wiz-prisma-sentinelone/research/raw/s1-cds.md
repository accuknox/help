## Frequently Asked Questions

### What is Cloud Data Security?

Cloud data security protects the data stored in cloud environments from threats, unauthorized access, and compliance violations.

For cloud data stores specifically, this means scanning files at the point of ingestion to stop malware before it can be processed, shared, or executed downstream. Singularity Cloud Data Security delivers this with a Static AI detection engine and autoscaling, machine-speed performance.

### How does Singularity Cloud Data Security detect malware?

Singularity Cloud Data Security uses a Static AI detection engine to analyze files at the point of upload.

Unlike signature-based tools that rely on known threat databases, the AI engine identifies both known malware and unknown zero-day threats in milliseconds, before any application can process the file.

### What cloud storage environments does Singularity Cloud Data Security support?

Singularity Cloud Data Security protects Amazon S3, Azure Blob Storage, and NAS file storage environments.

NAS support includes out-of-the-box compatibility with NetApp ONTAP and ICAP protocols, requiring no custom integrations or architecture changes.

### How is cloud data security different from DSPM?

Cloud data security focuses on detecting and stopping threats in cloud data stores at the point of ingestion. DSPM (Data Security Posture Management) focuses on discovering, classifying, and monitoring sensitive data across cloud environments.

The two are complementary. Singularity Cloud Data Security protects the data layer from malware, while DSPM capabilities within Singularity Cloud Native Security provide visibility into where sensitive data lives and how it's exposed.

### Does scanning data require moving it outside my environment?

No. Singularity Cloud Data Security scans files locally within the environment where they reside. Data never leaves your cloud account or storage infrastructure, eliminating egress concerns and supporting compliance with regulatory frameworks that require data residency.

### How does cloud data security fit into a broader cloud security strategy?

Cloud data security closes the gap between posture management and runtime protection. CSPM tools typically cover misconfigurations, identity risks, and workload threats, but the data layer often remains a blind spot.

Singularity Cloud Data Security adds malware scanning at the storage layer, complementing Cloud Native Security for posture and Cloud Workload Security for runtime within the Singularity Cloud Security portfolio.
