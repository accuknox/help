## Frequently Asked Questions

What is Prisma Cloud?


Prisma Cloud is a comprehensive Cloud Native Application Protection Platform (CNAPP) that secures applications from code to cloud.

What deployment models are available for Prisma Cloud?


It is available in two deployment models: SaaS (Prisma Cloud Enterprise Edition) and Self-Hosted (Prisma Cloud Compute Edition).

What is Prisma Cloud Copilot?


Powered by Palo Alto Networks' Precision AI, Prisma Cloud Copilot allows users to easily address cloud risks by asking straightforward questions.

How does Prisma Cloud handle pricing and licensing?


Prisma Cloud uses a credit-based licensing module, offering flexibility for different usage models and business needs.

Does Prisma Cloud offer Cloud Security Posture Management (CSPM)?


Yes, it includes CSPM to help organizations continuously monitor and manage their cloud security posture and compliance.
