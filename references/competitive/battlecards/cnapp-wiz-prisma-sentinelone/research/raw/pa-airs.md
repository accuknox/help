## Frequently Asked Questions

What is Prisma AIRS?


Prisma AIRS is a comprehensive AI security platform designed to secure the entire enterprise AI ecosystem, providing protection for AI applications and LLM deployments.

What types of threats does Prisma AIRS protect against?


It provides protection against prompt injection, model tampering, and agentic threats, detecting malicious prompts and suspicious behavior patterns.

How does Prisma AIRS stop threats in real time?


It uses the Precision AI engine to continuously monitor AI traffic, detecting threats like prompt injection, sensitive data exposure, malicious URLs, and toxic content before they impact your AI workflows.

How does Prisma AIRS secure autonomous AI agents?


It provides dedicated AI Agent Security against risks like memory manipulation and tool misuse, ensuring safe interactions with tools and workflows.

What are the deployment modes for Prisma AIRS?


It offers deployment modes such as Network Intercept and API Intercept to secure AI applications, AI models, AI data, and AI agents.
