## Overview

### Secure your Microsoft Azure environment

Wiz is a premier cloud security partner with Microsoft, providing unified security for the entire Azure estate, from initial code development to advanced AI operations. As a certified Solutions Partner, Wiz integrates seamlessly with the Microsoft Marketplace—allowing customers to apply **100% of their Microsoft Azure Consumption Commitment (MACC)** toward the purchase—to streamline both procurement and cloud scaling.

By leveraging the **Wiz Security Graph** alongside native services like **Microsoft Sentinel**, organizations gain deep, agentless visibility into risks across VMs, containers, and PaaS offerings. This collaboration effectively "shifts security left" by catching vulnerabilities within Azure DevOps pipelines and provides robust guardrails for **Azure AI services**, ensuring that rapid innovation never comes at the cost of compliance or security.

Wiz is also a member of the **Microsoft Intelligent Security Association (MISA)**, and was awarded the **Commercial Marketplace Partner of the Year**.
