# Does Prisma Cloud Enterprise Edition offer DAST dynamic application security testing?

I cannot find information about **DAST (dynamic application security testing)** for **Prisma Cloud Enterprise Edition** in the docs available to me.

What the docs do describe under **Application Security** are scans and protections such as:

* **IaC security**, **Software Composition Analysis (SCA)**, **Secrets Security**, **CI/CD pipeline security**, and **container image scanning** in the software delivery lifecycle. See [Application Security](/content-collections/application-security/application-security.md).
* **SAST (Static Application Security Testing)** findings (for example, “Manage Third-Party Data Ingestion” discusses ingesting SAST findings and viewing SAST violations). See [Manage Third-Party Data Ingestion](/content-collections/application-security/risk-management/monitor-and-manage-code-build/third-party-ingest-manage.md).

If you meant *runtime* web/API protection (as opposed to DAST scanning), Prisma Cloud also includes **WAAS (WAF)** capabilities, documented here: [Web-Application and API Security (WAAS)](/admin-guide/32/web-application-and-api-security-waas/waas.md).
