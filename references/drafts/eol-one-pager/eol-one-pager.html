Act on End-of-Life Assets with the Rule Engine

Set one rule. AccuKnox opens a ticket or sends an alert each time it finds an end-of-life (EOL) asset.

1. Pick the conditionChoose Is EOL in a Rule Engine rule. Add more conditions, such as a new asset or a severity count above a limit.
2. Choose the actionCreate ticket in a connected ticketing integration, or Send to notification channel.
3. Let it runThe rule runs each time AccuKnox parses an asset file. You schedule nothing.

1Open Issues → Findings → Rule Engine → Create Rule

(1) Findings in the Issues menu. (2) The Rule Engine tab. (3) The Create Rule button.

2Choose Is EOL, Then Pick an Action

(1) The Is EOL condition under Conditions. (2) The two actions in the Actions list.

How the Rule Behaves

  • A rule never files the same ticket twice. If a ticket exists for the asset, later triggers send a notification only.
  • Asset tickets have their own template under Settings.
  • Prerequisite: connect a ticketing or notification integration first.
Also in the docs: the container scan FAQ lists Outdated Base Images, meaning images built on EOL base OS versions with unpatched CVEs. The docs apply EOL to an asset or a base OS, not to a single package.
