# Weekly Help Documentation Updates

**Period covered:** 2026-07-06 to 2026-07-13
**Subject line used:** Weekly Help Documentation Updates (Last 7 Days)

## Overview

This week's documentation work centered on two things: a major refresh of the AI Security section around AccuKnox's eight security modules, and a new VM Security track for agent-based scanning on Linux fleets. Four new pages went live, including dedicated Ubuntu and RHEL onboarding guides and a new Microsoft Edge browser plugin guide for Prompt Firewall. On the update side, the AI Security overview, use-cases, and glossary pages were rewritten to reflect the new module structure, an OpenShift-specific fix was added across three runtime security docs, and several cloud onboarding guides got refreshed screenshots. Navigation was also reorganized: AI/ML Security is now labeled AI Security throughout, and the GenAI browser plugin docs are now organized by browser instead of by app.

## New Documentation

**Agent-Based VM Scanning for Linux (Overview)**
https://help.accuknox.com/how-to/vm-security/agent-based/linux/
Introduces the new Agent-Based VM Security track for Linux fleets, covering prerequisites, the install script, air-gapped installation, and resource tuning for the AccuKnox VM Security agent. Serves as the landing page pointing to distro-specific guides. Useful for anyone scoping VM/bare-metal vulnerability and malware scanning.

**Ubuntu VM Fleet Onboarding**
https://help.accuknox.com/how-to/vm-security/agent-based/ubuntu/
Step-by-step onboarding for agent-based scanning on Ubuntu VMs, including fleet-wide rollout commands. Relevant for Solution Engineers onboarding customers running Ubuntu workloads outside Kubernetes.

**RHEL VM Fleet Onboarding**
https://help.accuknox.com/how-to/vm-security/agent-based/rhel/
Same onboarding flow as above, tailored to RHEL-specific commands and package management. Rounds out Linux distro coverage alongside the Ubuntu guide.

**Prompt Firewall Browser Plugin for Microsoft Edge**
https://help.accuknox.com/integrations/edge-browser-integration/
New installation guide for the Prompt Firewall browser plugin on Microsoft Edge, covering ChatGPT, Claude, GitHub Copilot, and Gemini. Fills a gap for customers standardized on Edge who previously had no dedicated guide.
