# Weekly Help Documentation Updates

**Period covered:** 2026-10-06 to 2026-10-13
**Subject line used:** Weekly Help Documentation Updates (Last 7 Days)

## Overview

This week AccuKnox published 2 new pages and made real changes to 5 existing pages. Cloud Security gained a guide to onboard a whole GCP organization. Container Registry gained a guide to choose which images get scanned. The Compliance Matrix now lives in the help site and lists 14 more frameworks, including AI frameworks. The On-Prem guides were renamed and gained a printable PDF. The v3.7 release notes were filled in with the full feature list.

## New Documentation

**Onboard a GCP Organization**
URL: https://help.accuknox.com/how-to/gcp-org-onboard/

This page connects a whole Google Cloud organization to AccuKnox with one Terraform script. After the run, AccuKnox lists the organization, its folders and its projects under Cloud Accounts. The customer no longer adds projects one at a time. It lists the permissions, tools and values needed before the run, because most failed runs come from a missing permission or a missing API. Send it to any GCP customer with many projects.

**Filter Registry Images with Scan Patterns**
URL: https://help.accuknox.com/how-to/registry-scan-patterns/

This page shows how to choose which container images and tags AccuKnox scans in a registry. It explains wildcards, the minus sign to exclude, and ranges such as `v[1-8]`. Patterns work the same on every registry. A registry with no include pattern scans nothing, so Support should know this rule. Use it to help customers skip old versions and cut scan cost.

## Updated Documentation

**Compliance Matrix**
URL: https://help.accuknox.com/support-matrix/compliance-matrix/

The matrix now lists 14 more frameworks. They include EU AI Act, ISO/IEC 42001, MITRE ATLAS, NIST AI Risk Management Framework and OWASP Top 10 for LLM Applications. It also adds RBI CSF, RBI IT Framework, SAMA Cyber Security Framework, and new CIS Benchmark versions for AWS and Azure. A new table covers Oracle Cloud (OCI). Use it to answer "do you support framework X" questions for AI and regional regulators.

**AccuKnox v3.7 Release Notes**
URL: https://help.accuknox.com/getting-started/3.7-release/

The page grew from one feature into a full list, grouped by area. It covers GCP role impersonation onboarding, CIEM at cloud onboarding, scans of running Kubernetes images with Windows node support, Groups, the Asset Rule Engine, the xBOM revamp, the AI Gateway, custom Prompt Firewall policies and App-based Source Code Security. The page is not linked in the navigation yet, so do not share it with customers until it is.

**On-Premise Installation Guide (previously On-Prem Deployment Guide)**
URL: https://help.accuknox.com/getting-started/on-prem-installation-guide/

The page has a new name. It keeps the same install steps.

**On-Prem Single Node Installation**
URL: https://help.accuknox.com/getting-started/on-prem-single-node-installation/

The page now links a printable PDF of the On-Prem Deployment Guide. Customers with offline or locked-down environments can download it. The PDF is also listed under Resources: https://help.accuknox.com/resources/On_Prem_Deployment_Guide_AccuKnox.pdf

**Product tour and walkthrough videos on solution pages**
URLs: https://help.accuknox.com/getting-started/ciem-overview/ , https://help.accuknox.com/getting-started/dspm-overview/ , https://help.accuknox.com/use-cases/shadow-ai-discovery/ , https://help.accuknox.com/how-to/k8s-security-onboarding/

Each page now embeds a short video of the product. CIEM, DSPM and Shadow AI Discovery have two-minute tours. Kubernetes security has a five-minute walkthrough, including a blocked attack inside a running workload. Use them as a quick demo link in customer follow-ups.
