# Weekly Help Documentation Updates

**Period covered:** 2026-07-13 to 2026-07-20
**Subject line used:** Weekly Help Documentation Updates (Last 7 Days)

## Overview

This week's work centered on cloud onboarding and a documentation-wide cleanup of open-source tool naming. Four new pages went live covering Terraform-based onboarding for AWS, Azure, and GCP standalone accounts, giving customers an infrastructure-as-code path alongside the existing console-based onboarding flows. On the update side, open-source scanner names (Opengrep, OWASP ZAP, Checkov, TruffleHog, Trivy) were scrubbed from customer-facing SAST, DAST, IaC, and secret-scan integration guides across more than twenty pages, so those docs now describe capabilities generically instead of naming the underlying engine. Two small but customer-visible labeling bugs were also fixed: inverted SAST/SQ-SAST card labels on the GitLab and Google Cloud Build integration pages, and a refreshed screenshot on the Azure cloud onboarding guide.

## New Documentation

**Terraform Cloud Onboarding**
https://help.accuknox.com/how-to/terraform-cloud-onboarding/
Landing page for onboarding standalone AWS, Azure, or GCP accounts to AccuKnox using Terraform instead of the console UI. Links out to the three provider-specific guides below. Useful for Solution Engineers working with customers who manage infrastructure as code.

**Terraform AWS Onboarding**
https://help.accuknox.com/how-to/terraform-aws-onboarding/
Onboards a standalone AWS account using a Terraform-provisioned IAM user, covering prerequisites, configuration, and verification. For customers who prefer Terraform over manual IAM setup.

**Terraform Azure Onboarding**
https://help.accuknox.com/how-to/terraform-azure-onboarding/
Onboards a standalone Azure subscription using a Terraform-provisioned Azure AD application and service principal. Mirrors the AWS guide's structure for Azure-specific resources.

**Terraform GCP Onboarding**
https://help.accuknox.com/how-to/terraform-gcp-onboarding/
Onboards a standalone GCP project using a Terraform-provisioned service account and IAM roles. Completes Terraform coverage across all three major clouds.

## Updated Documentation

- **SAST/DAST/IaC/Secret Scan integration guides** (Azure DevOps, Bitbucket, GitHub, GitLab, Google Cloud Build, Jenkins — over 20 pages under [integrations/](https://help.accuknox.com/integrations/)) — removed open-source scanner names (Opengrep, OWASP ZAP, Checkov, TruffleHog, Trivy) from titles, headings, and descriptions so pages read generically. Product UI labels and functional identifiers (Marketplace URLs, Action names, CLI scripts) were left untouched since customers still need those exact values to complete setup.
- **SAST Use Case** ([use-cases/sast-sq](https://help.accuknox.com/use-cases/sast-sq/)) — retitled from "SAST with Opengrep and AccuKnox" to "SAST Security - Detecting SQL Injection Vulnerabilities" and reworded body copy to drop the Opengrep name.
- **GitLab Integrations Overview** ([integrations/gitlab-overview](https://help.accuknox.com/integrations/gitlab-overview/)) — fixed swapped card labels; "SAST (Static Analysis)" and "SQ-SAST (SonarQube)" now point to the correct guides.
- **Google Cloud Build Integrations** — nav label "SAST (OpenGrep)" simplified to "SAST".
- **GitHub Integrations** — nav labels corrected so "SAST (SonarQube)" and the generic "SAST" entry point to the right guides (previously mismatched).
- **Azure Cloud Onboarding** ([how-to/azure-onboarding](https://help.accuknox.com/how-to/azure-onboarding/)) — refreshed the step 5 screenshot.
