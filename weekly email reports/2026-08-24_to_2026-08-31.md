# Weekly Help Documentation Updates

**Period covered:** 2026-08-24 to 2026-08-31
**Subject line used:** Weekly Help Documentation Updates (Last 7 Days)

## Overview

This week's update is small and focused on two areas: a new Resources page and two onboarding fixes. AccuKnox added one new page, a Managed Cloud Security Services overview, to the Resources section. The team also corrected an outdated Helm command in the Kubernetes cluster onboarding guide and clarified the pre-install steps for Linux VM agent installation. No pages moved, and no navigation sections were removed.

## New documentation

**Managed Cloud Security Services**
URL: https://help.accuknox.com/resources/managed-cloud-security-services/

This page introduces AccuKnox's Managed Cloud Security Services offering. It embeds a downloadable PDF that covers service scope, delivery model, and support commitments. Solution Engineers and Customer Success can point prospects and customers here when a managed-service conversation comes up, instead of sending the PDF by hand.

## Updated documentation

**Cluster Onboarding with Access Keys**
URL: https://help.accuknox.com/how-to/cluster-onboarding-access-keys/

The Helm install command had two errors. The cluster name flag was wrong, `global.agents.clusterName` instead of `global.clusterName`, and the chart version pinned in the docs was outdated (v0.1.16). Both are now fixed. The command also gained a new flag, `global.inClusterScan.enabled=true`, to turn on in-cluster scanning, and the chart version now points to v0.1.49. Any customer who copied the old command would have hit a Helm error. Tell customers running into onboarding failures to re-copy the command from the page.

**VM Security, Agent-Based, Linux, Overview**
URL: https://help.accuknox.com/how-to/vm-security/agent-based/linux/

The installation script section now spells out four values to replace before running the install command: the Artifact API Token, the label, the endpoint URL, and the Tenant ID. Before, the page only mentioned two of the four. Customers following the old version were more likely to skip the endpoint URL or Tenant ID and get a failed install.

## This week's highlights

- New page: Managed Cloud Security Services, with a downloadable service overview PDF, live under Resources.
- Fixed: the Kubernetes cluster onboarding Helm command had a wrong flag name and a stale chart version. Both are corrected.
- Clarified: the Linux VM agent install guide now lists all four values a customer must replace before running the script.
- No pages were removed or renamed this week.
