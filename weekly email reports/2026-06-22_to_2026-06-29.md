## Overview

Two new integrations areas opened up this week: Sumo Logic log forwarding and AccuKnox's own Secrets Manager for on-prem deployments. A new SAST Language Support Matrix also went live, giving a single reference for which languages and rule engines are covered. Three brand-new pages published in total, plus small updates to the SBOM FAQ and Support Matrix index.

## New Documentation

**Sumo Logic Syslog Integration**
https://help.accuknox.com/integrations/sumologic-syslog/
Explains how to forward AccuKnox runtime security events to Sumo Logic via a self-hosted Rsyslog relay over TCP/TLS. Covers configuring the Sumo Logic Cloud Syslog source, the Rsyslog VM, and the AccuKnox Rsyslog channel. Useful for customers who already centralize logs in Sumo Logic.

**Sumo Logic Webhook Integration**
https://help.accuknox.com/integrations/sumologic-webhook/
A lighter-weight alternative to the syslog method — configures a Sumo Logic hosted HTTP source and an AccuKnox webhook channel to post runtime events directly, no relay VM required.

**AccuKnox Secrets Manager — On-Prem Deployment Guide**
https://help.accuknox.com/getting-started/secrets-manager-onprem-deployment/
New guide for deploying AccuKnox Secrets Manager on Kubernetes via Helm. Positions the product as a drop-in replacement for HashiCorp Vault — encrypted secrets storage, short-lived dynamic secrets, identity-based access control, and full audit logs. Relevant for on-prem customers evaluating secrets management.

**SAST Language Support Matrix**
https://help.accuknox.com/support-matrix/sast-support-matrix/
New reference table listing every language AccuKnox SAST scanning supports, broken out by rule engine (Python, Terraform/HCL, JavaScript, TypeScript, C/C++, and more) with rule counts per engine. Useful for pre-sales conversations about language coverage.
