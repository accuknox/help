# Weekly Help Documentation Reports

Archive of the weekly documentation-change reports generated by the `help-docs-summary` scheduled task. Each report reviews everything published to `main` in the preceding 7 days and is written for Solution Engineers, Customer Success, Support, and other customer-facing teams.

## Naming convention

Files are named by the date range they cover:

```
<start-date>_to_<end-date>.md
```

Both dates are `YYYY-MM-DD`, and `<end-date>` is the date the report was generated. Sorting the files alphabetically also sorts them chronologically.
