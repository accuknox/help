## New Documentation

**Agentless VM Scan Cloud Cost**
URL: https://help.accuknox.com/resources/agentless-scan-cost/

Agentless VM scanning runs a scanner VM inside the customer's own cloud account, so the cloud provider bills the customer for it. This page gives the monthly cost of one scanner in one region at list prices: about $68 on AWS, $67 on Azure and $30 on GCP, before usage charges. It lists each resource the scanner creates, shows that scanning across zones adds no data transfer charge, and explains when to run one scanner per zone. AccuKnox licensing is not part of these numbers. Send it to any customer who asks "what will agentless scanning add to my cloud bill" during a PoC or a pricing talk.

## Updated Documentation

**AI Security FAQ**
URL: https://help.accuknox.com/faqs/ai-security/

The page has 8 new questions, from customer and partner calls. They answer:

- How AccuKnox finds unmanaged AI agents, such as OpenClaw or an old LiteLLM version, on VMs and endpoints, with four discovery paths.
- How to let an approved offensive-security agent through without the Prompt Firewall blocking it.
- How to stop AI agents from going around the AccuKnox gateway.
- What happens when a user gives an agent a personal access token and the agent calls an API directly.
- How to run AI agents in an AgentZ sandbox from the first run, including on-premises and air-gapped.
- How a security team checks a Hugging Face model before it enters the model registry.
- How Knox RT red teaming differs from a one-shot prompt scan.
- The four ways to route AI traffic to the Prompt Firewall: browser plugin, gateway proxy, SDK and cloud API gateway.

Six new diagrams support these answers. Use this page first for AI Security questions from prospects.
