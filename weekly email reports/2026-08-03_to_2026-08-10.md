# Weekly Help Documentation Updates

**Period covered:** 2026-08-03 to 2026-08-10
**Subject line used:** Weekly Help Documentation Updates (Last 7 Days)

## Overview

The v3.6 release notes went live this week, and they are extensive: eleven feature sections covering findings automation, cloud security, policy management, host security, AI security, and application security. Three new pages joined the site: an Enterprise SSO (SAML) guide, a FortiGate SIEM log ingestion guide, and an Integration Support Matrix that catalogs the full connector surface in one place. A downloadable AWS CDR Deployment Guide PDF was added to Resources, and screenshots across the site are now click-to-enlarge. On the cleanup side, a handful of pages had placeholder-looking credential data scrubbed from example command output.

## New Documentation

**AccuKnox v3.6 Release Notes**

https://help.accuknox.com/getting-started/3.6-release/

The v3.6 notes moved from draft to published this week, with a highlights video and banner up top. Eleven sections cover the release: automated findings lifecycle status, per-account Checks Management, Smart Tickets parent-child automation, SBOM license findings, simplified AWS account onboarding, a SAMA compliance mapping, a new Security Graph, Microsoft 365 SSPM scanning, AWS SCP policy support, bulk policy actions, STIG and CIS coverage for Ubuntu, KubeArmor updates, Red Teaming moved onto the Assets page, and the Gen AI Prompt Firewall browser plugin. This is the reference for any v3.6 conversation with a customer or prospect.

**Enterprise SSO (SAML) with AccuKnox**

https://help.accuknox.com/integrations/saml-sso/

A vendor-neutral SAML 2.0 setup guide that works with Microsoft Entra ID, Okta, PingFederate, OneLogin, ADFS, Google Workspace, JumpCloud, or any other SAML identity provider. Walks through the two-way exchange of configuration values between AccuKnox and the customer's IdP, with no code work required on the customer side. Hand this to any prospect or customer whose security team asks about SSO before rolling AccuKnox out past a pilot group.

**FortiGate Logs to AccuKnox SIEM**

https://help.accuknox.com/integrations/fortigate-siem/

Shows how to forward FortiGate firewall Syslog events through an Ubuntu middleware server into AccuKnox SIEM, converting raw Syslog into structured NDJSON along the way. Useful for any customer running FortiGate who wants firewall events alongside their other security telemetry in AccuKnox.

**Integration Support Matrix**

https://help.accuknox.com/integrations/support-matrix/

A single page answering "does AccuKnox support X" for the full connector surface: 174 MCP servers, 158 inference providers, every SIEM that reads syslog or CEF, and 130-plus step-by-step integration guides. Good first stop for a Solution Engineer fielding an integration question mid-call, since it frames support by format (any syslog SIEM, any SARIF-emitting scanner) rather than a fixed vendor list.

**AWS CDR Deployment Guide (PDF)**

https://help.accuknox.com/resources/AccuKnox_AWS_CDR_Deployment_Guide.pdf

A printable, downloadable version of the AWS CDR setup guide, linked from both the Resources page and the CDR for AWS Setup Guide itself. Useful for customers who want an offline copy for an internal security review or change-management ticket.

## Navigation Changes

The Integration Support Matrix page was added to both the Integrations menu and the Support Matrix menu, so it is reachable from either path. The v3.6 release notes were uncommented in the Getting Started > Release Notes menu and are now listed alongside v3.5, v3.4, and earlier versions. The new SAML SSO guide was added under Integrations > SSO, and the new FortiGate guide was added under a new "Log Ingestion into AccuKnox SIEM" grouping in Integrations. The AWS CDR Deployment Guide PDF was added under Resources. No existing pages were moved or renamed, so previously shared links still work.
