# Weekly Help Documentation Updates

**Period covered:** 2026-07-28 to 2026-08-04
**Subject line used:** Weekly Help Documentation Updates (Last 7 Days)

## Overview

This was a heavy integrations week. AccuKnox shipped unified code-analysis scan guides for GitHub, GitLab, and Bitbucket, so a single pipeline step now covers SAST, SCA, Secret, IaC, ML Static Scan, and SBOM instead of one page per scanner. Jenkins picked up two new pages: a combined xBOM guide (SBOM, CBOM, and AIBOM in one pipeline) and a filesystem SBOM guide. Two more pages, v3.7 release notes and app-based source code onboarding, are drafted but still held back from navigation.

## New Documentation

**Running Code Analysis Scans with AccuKnox in a GitHub CI/CD Pipeline**

https://help.accuknox.com/integrations/github-unified-code-analysis-tool/

Replaces the separate-action approach with one AccuKnox GitHub Action that runs any combination of SAST (OpenGrep), SCA (Trivy), Secret (TruffleHog), IaC (Checkov), ML Static Scan (ModelScan), and SBOM. Customers pick scans through a single `scan_type` input instead of wiring up six workflow steps. Point GitHub customers here first when they ask about consolidating their pipeline.

**Running Unified Scans with AccuKnox in a GitLab CI/CD Pipeline**

https://help.accuknox.com/integrations/gitlab-unified-code-analysis-tool/

Same consolidated-scan model as the GitHub guide, delivered as a GitLab CI/CD component instead of six separate per-scan components. Covers SAST, SCA, Secrets, IaC, ML, and SBOM from one config block.

**Running Unified Scans with AccuKnox in a Bitbucket Pipeline**

https://help.accuknox.com/integrations/bitbucket-unified-code-analysis-tool/

The Bitbucket equivalent, packaged as a single pipe. Scan selection happens through a `SCAN_TYPE` variable (`sast`, `sca`, `secret`, `iac`, `ml`, `sbom`), run sequentially in one pipeline step.

**xBOM (SBOM + CBOM + AIBOM) for Jenkins**

https://help.accuknox.com/integrations/jenkins-xbom/

Generates all three bills of materials, software, cryptographic, and AI/ML, in one Jenkins pipeline using the AccuKnox xBOM plugin. AIBOM pulls model metadata from HuggingFace, so this is the page to hand a customer asking about AI supply-chain visibility, not just open-source dependencies.

**Generating Filesystem SBOMs in Jenkins**

https://help.accuknox.com/integrations/jenkins-sbom-filesystem/

A CycloneDX SBOM generated directly from a Git repository's filesystem in Jenkins, uploaded to a pre-created AccuKnox project. Useful when a customer wants dependency visibility without a container build step.

**FortiGate Logs to AccuKnox SIEM**

https://help.accuknox.com/integrations/fortigate-siem/

Walks through forwarding FortiGate Syslog events to an Ubuntu middleware server, converting them to NDJSON, and ingesting them into AccuKnox SIEM. This is the first page in a new log-ingestion section built to hold future firewall and network-device sources.
