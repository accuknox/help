# Weekly Help Documentation Updates

**Period covered:** 2026-10-26 to 2026-11-02
**Subject line used:** Weekly Help Documentation Updates (Last 7 Days)

## Overview

This week AccuKnox published 5 new pages and the v3.7 release notes. Secrets Manager got the most work: 3 new pages on security, the REST API and support terms, plus a multi-region disaster recovery plan. Shadow AI Discovery now covers Linux, Windows and macOS endpoints, with screenshots of each AI tool it found. A new guide onboards Red Hat OpenShift clusters from a private registry. DSPM and CIEM now carry a "New" label as generally available modules, and "GRC" is now called "Compliance" across the docs.

## New Documentation

**AccuKnox v3.7 Release Notes**
URL: https://help.accuknox.com/getting-started/3.7-release/

The v3.7 release notes are now live, with a cover image of the eight headline features. Highlights include GCP onboarding through role impersonation, CIEM at cloud onboarding, scans of running Kubernetes images, the Asset Rule Engine and Groups-based access control. Two late additions cover OpenShift onboarding and Shadow AI discovery on endpoints. Send this page to any customer who asks what changed in v3.7.

**OpenShift Cluster Onboarding for CWPP and KSPM**
URL: https://help.accuknox.com/how-to/openshift-onboarding/

OpenShift blocks the AccuKnox agents by default through Security Context Constraints (SCCs). This guide creates the KubeArmor SCC, grants SCCs to each agent service account, and then installs the agents, KubeArmor and the KSPM jobs with one Helm command. Every image comes from the customer's own private registry, and the guide covers clusters behind an HTTP proxy. Use it for any OpenShift PoC or onboarding call.

**Agent-Based Scanning for macOS**
URL: https://help.accuknox.com/how-to/vm-security/agent-based/macos/

This page installs the Omni agent on a Mac and shows how to confirm the daily scan ran. It then shows where the discovered AI tools appear in the console, under AI/ML Security, Assets, Unmanaged. It lists the AI tools AccuKnox validated on macOS, such as Gemini CLI, Kiro and Continue. Share it with customers who want to find shadow AI on developer laptops.

**Secrets Manager Security and Encryption**
URL: https://help.accuknox.com/secrets-manager/security/

This page explains how Secrets Manager protects secrets on disk and in transit. A chain of three keys guards the data, and the unseal key splits into 5 shares, of which any 3 unseal the server. It also covers key rotation without downtime, emergency seal, auto-unseal with a KMS or HSM, TLS, access control, audit logs and KubeArmor hardening. Send it to security reviewers and anyone filling out a security questionnaire.

**Secrets Manager REST API Reference**
URL: https://help.accuknox.com/secrets-manager/rest-api/

Every Secrets Manager action is an HTTPS call, compatible with the HashiCorp Vault HTTP API. This page covers the base URL, how to log in and send the token, the endpoints teams use most, and what each error code means. It also shows how to download the full OpenAPI document from the customer's own server. Developers and integration teams should read it.

**Secrets Manager Support and SLA**
URL: https://help.accuknox.com/secrets-manager/support/

This page lists response times by severity and support package. A P1 ticket gets a first response within 1 hour on Gold and Platinum, and within 4 hours on Silver. Platinum covers 24 hours a day, 7 days a week. It also explains how to pick a severity, how to open a ticket by email, and how the uptime commitment depends on where Secrets Manager runs. Use it when a buyer asks about support terms.

## Updated Documentation

**Shadow AI Discovery**
URL: https://help.accuknox.com/use-cases/shadow-ai-discovery/

The page now explains the two discovery paths: cloud discovery and endpoint discovery. Endpoint discovery finds AI tools on Linux, Windows and macOS, even when nobody runs them. It sorts them into CLI agents, desktop apps and IDE extensions, with a screenshot of each validated tool. A new section lists what endpoint discovery does not do.

**Agent-Based Scanning for Windows**
URL: https://help.accuknox.com/how-to/vm-security/agent-based/windows/

A new section shows how to confirm the scan ran: check the scheduled task, read the scan log, then find the results in the console. Screenshots show Codex CLI, the ChatGPT desktop app and Cline as AccuKnox found them on a Windows endpoint. The air-gapped steps now set up the AI agent database next to the vulnerability database.

**Agent-Based Scanning for Linux**
URL: https://help.accuknox.com/how-to/vm-security/agent-based/linux/

The page now shows where to find the discovered AI tools in the console after the first scan. It adds the six AI coding agents AccuKnox validated on a Linux VM, the log file locations, and how to raise the default 2G memory and 10% CPU limits when a scan runs out of memory.

**Compliance Matrix**
URL: https://help.accuknox.com/support-matrix/compliance-matrix/

The matrix now has two tabs, Cloud and VM. The VM tab lists STIG support for Ubuntu, RHEL and its relatives, Windows 10 and 11, Windows Server 2019, 2022 and 2025, and Kubernetes. It also lists CIS support for Ubuntu 22.04 and 24.04. Rows marked "TBD" are gone.

**Secrets Manager High Availability and Backup**
URL: https://help.accuknox.com/secrets-manager/high-availability/

A new section explains multi-region disaster recovery. Customers run one three-node cluster in each region and copy every snapshot to the second region. With the default 15-minute snapshot schedule, a regional failover loses at most 15 minutes of secret changes. The page gives the steps to prepare the DR region, fail over and fail back.

**Secrets Manager Deployment Guide**
URL: https://help.accuknox.com/secrets-manager/deployment/

A new table compares the three ways to run Secrets Manager: managed shared, managed dedicated and self-hosted. It covers fit, backups, API limits, audit logs, location and who runs it. A production checklist lists nodes, storage, ports, TLS, the snapshot bucket and the 5 key holders.

**Secrets Manager External Secrets Operator**
URL: https://help.accuknox.com/secrets-manager/external-secrets/

The page now gives the full steps to trust an application cluster that runs somewhere else. Earlier versions left these steps as a placeholder.

**Secrets Manager FAQ**
URL: https://help.accuknox.com/faqs/secrets-manager/

Four new questions answer how secrets are protected at rest, whether there is a REST API, how disaster recovery across regions works, and what support SLA comes with the product.
