# Weekly Help Documentation Updates

**Period covered:** 2026-05-25 to 2026-06-01
**Subject line used:** Weekly Help Documentation Updates (Last 7 Days)

## Overview

A major week for CI/CD documentation: the entire Jenkins integration section was rebuilt around a new ASPM Scanner plugin, with a dedicated install guide and consistent per-scan-type pages (SAST, IaC, Container, Secret, SBOM, and a new Multi-Artifact/SCA scan). A new Firefox guide for Prompt Firewall and a new Apigee proxy integration guide also shipped. The Runtime Security architecture page introduced a new "8-step Runtime Security Journey" framework that also now appears across several use-case pages.

## New Documentation

**Prompt Firewall Browser Plugin for Firefox**
https://help.accuknox.com/integrations/openai-firefox-browser-integration/
New installation guide for the Prompt Firewall browser plugin in Mozilla Firefox, complementing the existing Chrome/Brave/Edge guide.

**Apigee Proxy Integration with Prompt Firewall**
https://help.accuknox.com/integrations/apigee-integration/
New guide for fronting an LLM backend with an Apigee proxy that validates prompts against the AccuKnox API before forwarding to the LLM. Built with `continueOnError` policies so a validation-API outage never blocks the primary traffic flow.

**Installing ASPM Jenkins Plugin**
https://help.accuknox.com/integrations/jenkins-install/
New one-time setup guide for the AccuKnox ASPM Scanner Jenkins plugin — the foundation for all the per-scan-type Jenkins pages below.

**Multi-Artifact (SCA) Scanning in Jenkins**
https://help.accuknox.com/integrations/jenkins-artifact-scan/
New guide for scanning multiple build artifacts (jars, binaries, archives, lockfiles) for known CVEs in a single Jenkins pipeline stage.

**Generating Container SBOMs in Jenkins**
https://help.accuknox.com/integrations/jenkins-sbom/
New guide for producing a CycloneDX SBOM for a container image from a Jenkins pipeline and uploading it to AccuKnox.
