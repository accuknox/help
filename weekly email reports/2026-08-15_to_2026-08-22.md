# Weekly Help Documentation Updates

**Period covered:** 2026-08-15 to 2026-08-22
**Subject line used:** Weekly Help Documentation Updates (Last 7 Days)

## Overview

A quieter week than the last one, with one large addition. AgentZ now has its own
top-level section on the help site, and its landing page is the only new page this week.
Two existing pages changed in ways customers notice. The GitLab Unified Code Analysis
page carries a corrected pipeline path, and the Sample Reports page adds a Microsoft 365
CIS Benchmark report. The site banner also moved from v3.5 to v3.6.

## New Documentation

**AgentZ**

https://help.accuknox.com/agentz/

AgentZ is the AccuKnox runtime for production AI agents. This page is its home on the
help site. It explains the zero trust model in plain words. Each agent starts in a
default deny sandbox, holds no secret, and writes every action to a trace you can replay.
The page covers the four steps of build, run, automate, and govern. It also shows the six
control plane parts, nine product screenshots, and the supported model providers. Read
this page before any call about AI agent security. It links the free trial, the open
source repository, the demo video, and the full AgentZ documentation site.

## Updated Documentation

**GitLab Unified Code Analysis**

https://help.accuknox.com/integrations/gitlab-unified-code-analysis-tool/

Every pipeline example on this page now points at the correct CI component path. The old
path used `accuknox` and the correct path uses `accu-knox`. Nine code samples changed,
which covers every scan type: SAST, SCA, secret, IaC, ML, and SBOM. Tell any customer who
copied a GitLab pipeline from this page before this week to copy it again. The old path
fails.

**Sample Reports**

https://help.accuknox.com/resources/sample-reports/

The page adds a Microsoft 365 CIS Benchmark sample report. Customers who run Microsoft
365 can now see the report format before they buy. The report opens from this direct
link: https://help.accuknox.com/resources/assets/MS365_CIS_Report.pdf

**Site banner**

https://help.accuknox.com/getting-started/3.6-release/

The banner at the top of every page now announces AccuKnox v3.6 and links the v3.6
release notes. It names two changes. Findings close on their own after a confirmed fix,
and AWS onboarding no longer needs access keys. The banner link is now white in both
light mode and dark mode, which reads better than the old yellow and blue.

## New Documentation Sections

**AgentZ**

https://help.accuknox.com/agentz/

AgentZ is a new top-level entry in the site navigation. It sits between Resources and
FAQs, and it carries a "New" badge in the tab bar and in the sidebar. The section holds

documentation site. Sales, Solution Engineers, and Support all benefit, because questions
about AI agents now have one place to land.
