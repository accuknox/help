# Weekly Help Documentation Updates

**Period covered:** 2026-06-08 to 2026-06-15
**Subject line used:** Weekly Help Documentation Updates (Last 7 Days)

## Overview

The biggest AI Security expansion in recent weeks: a new "Red Team Custom Models" track shipped with dedicated guides for AWS Bedrock, NVIDIA Triton, and vLLM, plus a new Claude browser plugin guide for Prompt Firewall. The v3.5 Release Notes page grew substantially across three separate updates, covering AI inventory, dashboard widgets, and collector-based scanning. Cloud AI/ML onboarding guides for AWS, Azure, and GCP were also reworked with clearer IAM permission steps. Five new pages published in total, alongside a site-wide "Copy page" feature for readers.

## New Documentation

**Red Teaming Amazon Bedrock Models via AccuKnox Collector**
https://help.accuknox.com/how-to/aiml-bedrock-collector/
New guide for red-teaming a single Bedrock model without onboarding the whole AWS account — a lighter-weight alternative aimed at teams that just need to test one model's inference endpoint.

**Custom Model Red Teaming (Overview)**
https://help.accuknox.com/how-to/aiml-custom-model-redteaming/
New landing page tying together the Bedrock, Triton, and vLLM collector guides under one "Custom Model" red teaming umbrella.

**Red Teaming NVIDIA Triton Models via AccuKnox Collector**
https://help.accuknox.com/how-to/aiml-triton-collector/
New guide for pointing the AccuKnox Custom Model collector at a Triton Inference Server endpoint, covering both the KServe v2 `/infer` protocol and the `/generate` endpoint used by TRT-LLM/vLLM backends.

**Red Teaming vLLM Models via AccuKnox Collector**
https://help.accuknox.com/how-to/aiml-vllm-collector/
New guide for red-teaming models served behind vLLM's OpenAI-compatible API, covering both chat and completions endpoints.

**Prompt Firewall Browser Plugin for Claude**
https://help.accuknox.com/integrations/claude-browser-integration/
New installation guide for the Prompt Firewall browser plugin specifically for Claude in Chromium-based browsers, alongside the existing ChatGPT guide (same plugin covers both apps).
